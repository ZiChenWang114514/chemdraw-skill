# Public, self-authored figure example

Run `python replay.py NEW_OUTPUT_DIRECTORY` in the upgraded toolkit environment, then native-render `figure.cdxml` using `render_cdxml_files`. Compare the actual preview with `reference.png` using the image-review helper and inspect it.

`figure.json` is the editable input manifest. It covers six reaction arrows, single/pair electron curves, rich text, a highlighted chiral molecule, an enhanced AND stereo group and atom numbering. `reference.cdxml` and `reference.png` are actual toolkit/ChemDraw outputs, not a paper reproduction or a universal pixel benchmark.

This public replay exercises composition and validation without network access. For image-recognition work, supply your own authorized paper image and follow the fast guide; raw uploaded images and session-specific DECIMER responses are not part of this repository. Example coordinates belong to this fixture only.
