# Nature Portfolio house style

How reaction schemes are drawn in Nature Portfolio chemistry journals (Nature, Nature Chemistry, Nature Communications, Nature Synthesis, Nature Catalysis), measured from open-access figures. Machine-readable card: `toolkit/cdxml_toolkit/publication/house_styles/nature_portfolio.json` (base preset `nature`).

## Sources (CC BY 4.0)

- Wang et al., Nat. Commun. 2025, 16, 1108, DOI 10.1038/s41467-025-56377-w: Table 1 scheme (`evidence/nature_portfolio-01.png`), Fig. 2 header (`-02`).
- Zhao, Jia and Wang, Nat. Commun. 2024, 15, 2415, DOI 10.1038/s41467-024-46576-2: Fig. 2 header (`-03`).

## Measurements (mean of three crops, 300 dpi page renders)

- Bond length / atom-label cap height: 2.21 (range 1.6 to 2.8).
- Line width / bond length: 0.062.
- Bold wedge width / bond length: 0.24 (one paper only).
- Arrow shaft / bond length: 11.1.
- Atom labels: Arial or Helvetica, about 7 pt at print size.

## Conventions

- Compound numbers bold black, suffix not italic (both papers).
- Yield written as a plain percentage after the bold number on the same line, e.g. 3a, 85%, 90% ee (both papers).
- Catalysts and ligands above the arrow; additives, solvent, temperature and time below (both papers).
- Kekulé rings (both papers).
- The substrate-derived skeleton coloured teal, about #0078B2, in substrate and product (both papers).
- Reagent text black; plain arrow.
- Abbreviated groups seen in both papers: OMe, Ph, Me, Et, tBu, CN.
- Not settled by two papers: red new bond (#FF0000), second substrate blue (#0000FF), inline A + B layout; each seen in one paper only.
