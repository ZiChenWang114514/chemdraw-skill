# macmillan_group

Reaction-scheme house style of the MacMillan group (Princeton University), measured from open-access figures. Base preset: acs1996.

## Sources

- MacMillan et al., J. Am. Chem. Soc. 2026 (A general photoredox platform for the hydroarylation of olefins). DOI 10.1021/jacs.6c14333. Licence CC BY 4.0.
- MacMillan et al., J. Am. Chem. Soc. 2026 (Oxyalkylation of alkenes via triple radical sorting). DOI 10.1021/jacs.6c03814. Licence CC BY 4.0.

## Measurements

- Bond length / atom-label cap height: 2.25
- Line width / bond length: 0.055
- Bold wedge width / bond length: None
- Arrow length / bond length: 5.2

## Conventions

- compound_label_face: bold
- compound_label_color: #000000
- compound_label_italic_suffix: False
- yield_placement: under_product_label
- yield_format: {value}% yield
- conditions_split: None (crop 02 puts all conditions above the arrow, crop 03 puts only the scale below; not determined)
- substrate_layout: inline_plus
- abbreviate_groups: ['Boc', 'Cbz', 'Me', 'Et', 'Ar', 'TMS', 'OMe']
- aromatic_rings: kekule
- new_bond_color: #0C549C (dark blue in all crops; pixels read #0C2484 (crop 01) and #0C549C (crops 02, 03))
- substrate_colors: None
- highlight_fill: None (grey halo behind the new bonds in crop 02 only)
- reagent_text_color: #000000
- arrow_style: plain
- show_plus_sign: False

## Signature features

- yield line such as 6, 76% yield with bold number, comma and the word yield
- new bonds and transferred H or D drawn in dark blue
- substrates placed side by side with no plus sign
- catalyst icons (PC, Ir, Ni discs, light bulb) on or before the arrow
- italic descriptor text under starting materials
