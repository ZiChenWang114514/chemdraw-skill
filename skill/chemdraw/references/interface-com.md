# ChemDraw COM Interface Catalog

> Generated by `cdx.py regen-catalog` from the catalogs in `cdxml_toolkit/catalog/data`. Do not hand-edit.

Read from the type libraries inside `ChemDraw.exe` and `ChemDrawCtl.dll` of ChemDraw, verified on 22.2.0/win; reading them does not start ChemDraw.
Object library `ChemDraw`: 229 types, 1821 members. Control library: 226 types, 1907 members, 8 types not in the object library.

## Reaching it

- `ChemDraw.Application` is the root: `Documents` → `Document` → `Objects` and the typed collections (`Atoms`, `Bonds`, `Graphics`, `Tables`, `PlasmidMaps`, ...). `MenuBars` exposes the menus ([interface-menu.md](interface-menu.md)).
- No generic COM tool exists yet. The members marked T1 below are already used by `convert_cdx_cdxml` and `render_to_png`; all other members are documented here so that nothing is guessed.
- Run native work through the tools: they take the shared ChemDraw lock and use a private instance.

Tiers: **T1** A dedicated tool does the operation. **T2** Reachable through a generic tool, with a recipe that was run and checked. **T3** Documented. Not opened as a tool, or reachable only through a generic tool without a verified recipe. Rows: T1 8, T2 17, T3 1641.
