The agent’s drawing has one error. Compare it with the correct structure and click the wrong atom or bond. These structures are wrong on purpose, for this game only.

This canvas runs in your browser and needs no ChemDraw. Saved .cdxml files open in ChemDraw; to have an agent render natively, first install the Skill and desktop ChemDraw.

Your progress stays in this browser and is never uploaded.
