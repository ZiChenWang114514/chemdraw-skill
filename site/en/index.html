Let your AI agent draw in ChemDraw

ChemDraw Skill lets an AI coding agent make ChemDraw files. You say which molecule or figure you want; the agent looks the structure up, writes the CDXML, has ChemDraw render it and reads the file back to check it. What you open is an ordinary ChemDraw document, with atoms and bonds you can keep editing. The same Skill also does the arithmetic around a reaction: reagent amounts, yields, characterization text and atom maps.

Four steps, each one checkable

A figure can look right and still be wrong. So every step has a named input and output, and when something is off you can see which step it came from.

All four run through one entry point, cdx.py. Any agent that can run a shell command can call it; MCP is optional.

“aspirin”

  1. resolve_nameOPSIN, PubChem

    Ground the structure

    Start from a name, identifier, trusted SMILES or a DECIMER reading, and record where it came from. The model never invents SMILES.

    Show the command and its output
    $ cdx.py call resolve_name --json '{"query": "aspirin"}'
{"ok": true, "name": "aspirin", "smiles": "CC(=O)Oc1ccccc1C(=O)O", "formula": "C9H8O4",
 "mw": 180.159, "exact_mass": 180.0423, "source": "reagent_db", …}

    CC(=O)Oc1ccccc1C(=O)O

  2. buildACS Document 1996

    Draw natively

    Build CDXML that keeps stereo, charge and isotope information. Atoms, bonds and text stay editable in ChemDraw.

    Show the command and its output
    $ cat aspirin.json
{"objects": [{"type": "molecule", "smiles": "CC(=O)Oc1ccccc1C(=O)O", "at": [80, 60]}]}
$ cdx.py build aspirin.json aspirin.cdxml
{"cdxml": "…/aspirin.cdxml", "ok": true}

    aspirin.cdxml

  3. renderChemDraw, 300 dpi

    Render and look

    ChemDraw itself renders the file, and the agent opens the image to check labels, arrows, charges and crossings.

    Show the command and its output
    $ cdx.py render aspirin.cdxml
{"source": "…/aspirin.cdxml", "png": "…/aspirin.png", "ok": true}

    aspirin.png

  4. readbackChemScript, RDKit

    Read it back

    The saved file is read again to confirm the chemistry written is the chemistry intended. When readers disagree, the agent says so.

    Show the command and its output
    $ cdx.py chemscript-info aspirin.cdxml
Type:    structure
Name:    2-acetoxybenzoic acid
Formula: C9H8O4
SMILES:  CC(OC1=CC=CC=C1C(O)=O)=O
InChI:   InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12)
Atoms:   13
Bonds:   13

    C9H8O4 matches the input ✓

Reaction amounts, yields and the numbers around them

For a reaction you give as SMILES or a ChemDraw file, cdx.py calc runs ChemDraw's own Structure > Analyze Stoichiometry and opens the result in ChemDraw. You type an amount into the grid and ChemDraw computes the rest.

  • Equivalents, sample mass, molarity, density, volume and moles for each reactant and reagent; expected mass, measured mass, purity and yield for the product.
  • cdx.py calc --read returns the saved grid as data, so the agent quotes ChemDraw's numbers instead of its own. Reading needs no ChemDraw; drawing the grid needs desktop ChemDraw.
  • Your source file is never changed: the grid is written into a new copy.
  • Without ChemDraw, SI materials tables give amounts, concentration, atom economy and process mass intensity (PMI) for up to 100 reactions, with every default marked and safety reminders from a built-in table. A substance that is missing shows as "not listed". It is a reminder, not a replacement for the SDS.
  • Also available: characterization paragraphs in ACS order with the NMR peak counts checked, the overall yield and PMI of a multi-step route, and atom mapping with a reaction-type label.

Start in three steps

  • ChemDraw. Native rendering, the PNG in step 3 and Office embedding need licensed desktop ChemDraw on Windows or macOS. Without it the Skill still builds, edits, checks and recognises structures and runs the calculators.
  • Python. The installer runs on Python 3.9+ and finds a 64-bit Python 3.10–3.13 for the runtime on Windows, macOS or Linux.
  • Disk. The default runtime takes about 760 MB. --extras with no names installs the core only.
  • Optional. Add --opsin for name-to-structure through OPSIN, which needs Java (fetched on Windows, installed by you elsewhere). Text recognition in the image extra needs Tesseract.

Pick your agent and system and the commands update to match. For project-level installs and other options, see agent integration.

Common questions

Does this ChemDraw Skill work with any AI agent?

Yes, as long as the agent can read the skill instructions and run shell commands.

Every tool runs through cdx.py.

  • With skill discovery: the installer places the skill where Claude Code, Codex, Gemini CLI, GitHub Copilot, Cursor, OpenCode, Kimi CLI and pi look for skills.
  • Without skill discovery: point the agent's instruction file at SKILL.md.
Do I need an MCP server?

No. The command line covers every tool.

It keeps the same worker isolation, native ChemDraw lock and timeouts. Clients that prefer typed tool calls can still register the bundled MCP server.

Can it build SAR and substrate-scope figures from Excel data?

Yes. Bind trusted structures to CSV or XLSX data to produce editable SAR or substrate-scope figures.

Updating the data keeps unrelated manual layout edits. See the data-driven figures guide.

Will it make up reaction conditions or predict a mechanism?

No. For a figure drawn from a request, conditions, yields and measured values come only from what you gave.

  • A missing value stays missing, and the report says so.
  • A name it cannot resolve is refused instead of guessed.
  • Mechanisms are drawn from electron moves you list. An arrow that starts where there is no lone pair or charge is flagged, but the tool does not judge whether the mechanism is right.

See drawing a new reaction scheme.

Can it work out how much of each reagent to weigh?

Yes, with ChemDraw's own calculator.

  • cdx.py calc runs Structure > Analyze Stoichiometry on a reaction given as SMILES or a ChemDraw file and opens the grid in ChemDraw.
  • Type a mass, volume or equivalents in the grid, and ChemDraw computes the rest.
  • cdx.py calc --read reads the saved numbers back.

Without ChemDraw, SI materials tables give amounts in which every default is marked as assumed. See the chemistry reports guide.

How far can I trust the safety information?

Treat it as a reminder, and check the SDS of the product you actually use.

It comes from a built-in table of about fifty common solvents and reagents: GHS pictograms, H-statements, boiling and flash point.

A substance that is not in the table is shown as "not listed", never as safe.

Can it turn a structure image from a paper into an editable ChemDraw file?

Yes, as editable CDXML with a native ChemDraw preview.

The reconstruction workflow combines DECIMER recognition, structure checks, layout rebuilding and native visual review. See the reconstruction guide.

Does it work without ChemDraw installed?

Partly: it can create and check CDXML, but the native features need ChemDraw.

  • Without ChemDraw: the portable cdxml-toolkit runtime creates and checks CDXML on Windows, macOS and Linux.
  • With licensed desktop ChemDraw on Windows or macOS: native rendering, ChemScript checks and Office embedding.
