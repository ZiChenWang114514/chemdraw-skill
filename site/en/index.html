Let your AI agent draw in ChemDraw

ChemDraw Skill lets an AI coding agent make ChemDraw files. You say which molecule or figure you want; the agent looks the structure up, writes the CDXML, has ChemDraw render it and reads the file back to check it. What you open is an ordinary ChemDraw document, with atoms and bonds you can keep editing.

Four steps, each one checkable

A figure can look right and still be wrong. So every step has a named input and output, and when something is off you can see which step it came from.

All four run through one entry point, cdx.py. Any agent that can run a shell command can call it; MCP is optional.

“aspirin”

  1. resolve_nameOPSIN, PubChem

    Ground the structure

    Start from a name, identifier, trusted SMILES or a DECIMER reading, and record where it came from. The model never invents SMILES.

    Show the command and its output
    $ cdx.py call resolve_name --json '{"query": "aspirin"}'
{"ok": true, "name": "aspirin", "smiles": "CC(=O)Oc1ccccc1C(=O)O", "formula": "C9H8O4",
 "mw": 180.159, "exact_mass": 180.0423, "source": "reagent_db", …}

    CC(=O)Oc1ccccc1C(=O)O

  2. buildACS Document 1996

    Draw natively

    Build CDXML that keeps stereo, charge and isotope information. Atoms, bonds and text stay editable in ChemDraw.

    Show the command and its output
    $ cat aspirin.json
{"objects": [{"type": "molecule", "smiles": "CC(=O)Oc1ccccc1C(=O)O", "at": [80, 60]}]}
$ cdx.py build aspirin.json aspirin.cdxml
{"cdxml": "…/aspirin.cdxml", "ok": true}

    aspirin.cdxml

  3. renderChemDraw, 300 dpi

    Render and look

    ChemDraw itself renders the file, and the agent opens the image to check labels, arrows, charges and crossings.

    Show the command and its output
    $ cdx.py render aspirin.cdxml
{"source": "…/aspirin.cdxml", "png": "…/aspirin.png", "ok": true}

    aspirin.png

  4. readbackChemScript, RDKit

    Read it back

    The saved file is read again to confirm the chemistry written is the chemistry intended. When readers disagree, the agent says so.

    Show the command and its output
    $ cdx.py chemscript-info aspirin.cdxml
Type:    structure
Name:    2-acetoxybenzoic acid
Formula: C9H8O4
SMILES:  CC(OC1=CC=CC=C1C(O)=O)=O
InChI:   InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12)
Atoms:   13
Bonds:   13

    C9H8O4 matches the input ✓

What it handles

Ten kinds of drawing job, each with its own workflow.

Structures and reactions
Resolve names and identifiers; draw, edit, clean, merge, split, convert and render CDXML or CDX.
Paper figures
Crop the source, read it with DECIMER, compare side by side, fix the chemistry and assemble the layout.
Patent Markush
Extract a generic structure from a patent figure and its claims as CXSMILES, a V3000 molfile and editable CDXML.
Exams and lectures
ACS 1996 drawings from JSON with abbreviation nodes, rich text, annotations and boxed labels.
SAR and substrate scope
Updatable figures from CSV or Excel that keep your manual layout edits.
Molecule comparison
RDKit fingerprint similarity everywhere; exact identity checks through ChemScript on Windows or ChemDraw on macOS.
Mechanisms
Electron-pushing arrows, charges and counterions placed from explicit atom coordinates.
TLC and apparatus
Native TLC plates, lanes, spots and Rf; apparatus assembled from ChemDraw templates.
Spectra and lab records
Peak picking and range integration on 1D NMR, numeric data as editable curves; LCMS, SciFinder RDF and notebook workflows.
Word and PowerPoint
Embed live ChemDraw objects in Word and PowerPoint documents, built on Windows or macOS.

Start in three steps

The installer needs Python 3.9+ and finds a 64-bit Python 3.10–3.13 for the runtime on Windows, macOS or Linux. Native rendering and Office embedding need licensed desktop ChemDraw on Windows or macOS.

Pick your agent and system and the commands update to match. For project-level installs and other options, see agent integration.

Common questions

Does this ChemDraw Skill work with any AI agent?

Yes. The agent needs to read the skill instructions and run shell commands; every tool runs through cdx.py. The installer places the skill where Claude Code, Codex, Gemini CLI, GitHub Copilot, Cursor and OpenCode look for skills. For an agent without skill discovery, point its instruction file at SKILL.md.

Do I need an MCP server?

No. The command line covers every tool with the same worker isolation, native ChemDraw lock and timeouts. Clients that prefer typed tool calls can still register the bundled MCP server.

Can it build SAR and substrate-scope figures from Excel data?

Yes. Bind trusted structures to CSV or XLSX data to produce editable SAR or substrate-scope figures; updating the data keeps unrelated manual layout edits. See the data-driven figures guide.

Can it turn a structure image from a paper into an editable ChemDraw file?

Yes. The reconstruction workflow combines DECIMER recognition, structure checks, layout rebuilding and native visual review, and outputs editable CDXML with a native ChemDraw preview. See the reconstruction guide.

Does it work without ChemDraw installed?

The portable cdxml-toolkit runtime creates and checks CDXML on Windows, macOS and Linux. Native rendering, ChemScript checks and Office embedding need licensed desktop ChemDraw on Windows or macOS.
