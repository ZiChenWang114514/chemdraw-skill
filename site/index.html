让 AI 画出可编辑的 ChemDraw 结构式

ChemDraw Skill 是给 AI 编程 Agent 用的化学绘图技能。说一句话，Agent 就会确认结构、在 ChemDraw 里原生绘制，再把结果读回来核对。你拿到的是能继续编辑的 CDXML，而不是一张截图。

git clone https://github.com/ZiChenWang114514/chemdraw-skill.git
三步安装 在 GitHub 上查看源码

适用于 Claude Code、Codex、Gemini CLI、GitHub Copilot、Cursor、OpenCode，以及任何能执行命令行的 Agent。

结构有出处

结构来自数据库、ChemScript、OPSIN 或 DECIMER 识别，不让模型凭空编 SMILES。

真正可编辑

输出是原生 CDXML，原子、键和文字都能在 ChemDraw 里接着改。

一个入口

所有功能都走 cdx.py 一条命令，任何 Agent 都能调用，MCP 可选。

原生品质

由 ChemDraw 本身渲染和保存，保存后再回读核对化学结构。

每张图都经过四步

化学正确比看起来像更重要。Skill 把每次绘图都拆成能检查的步骤。

  1. 确认结构

    从名称、标识符、可信 SMILES 或 DECIMER 识别结果出发，记录来源。

  2. 原生绘制

    生成 CDXML，按 ACS Document 1996 等样式排版，保留立体、电荷和同位素。

  3. 渲染查看

    由 ChemDraw 输出 300 dpi PNG，Agent 打开图片逐项检查版面。

  4. 回读核对

    保存后重新读取文件，确认写进去的化学结构就是要画的那个。

能做什么

从一个分子到一整篇论文的插图，常见的化学绘图工作都有对应的工作流。

结构与反应
解析名称和标识符；绘制、编辑、清理、合并、拆分、转换和渲染 CDXML / CDX。
论文图复刻
裁剪原图、DECIMER 识别、并排比对、修正化学，组装条件与版面。
试卷与讲义
由 JSON 生成 ACS 1996 插图，支持缩写节点、富文本、中文注释和带框编号。
SAR 与底物拓展
由 CSV / Excel 生成可持续更新的 SAR 图和底物拓展图，保留手工排版。
分子比较
RDKit 指纹相似度；Windows 上可增加 ChemScript 精确身份检查。
反应机理
按原子坐标绘制电子箭头、电荷和抗衡离子。
TLC 与装置
原生 TLC 板、泳道、斑点和 Rf 计算；ChemDraw 装置模板组装。
谱图
一维 NMR 寻峰与区间积分，数值数据输出为可编辑曲线。
Word 与 PPT
在 Windows 版 Word、PowerPoint 中嵌入可双击编辑的 ChemDraw 对象。
实验记录
处理 LCMS、SciFinder RDF 和实验记录相关工作流。

三步开始使用

安装脚本需要 Python 3.9 以上，会自动找到 64 位 Python 3.10–3.13 作为运行时，Windows、macOS、Linux 都能装。原生渲染和 Office 嵌入需要 Windows 上已授权的 ChemDraw。

想装到 Codex、Gemini CLI 或 Cursor？把 --agent claude 换成对应名称，或用 agents 安装到通用目录。详见 Agent 接入说明。

  1. 安装

    git clone https://github.com/ZiChenWang114514/chemdraw-skill.git
cd chemdraw-skill
python scripts/install.py --agent claude agents --runtime --apply

  2. 检查本机能用哪些功能

    python ~/.claude/skills/chemdraw/scripts/cdx.py doctor

  3. 直接对 Agent 说

    用 ChemDraw Skill 把阿司匹林画成可编辑 CDXML，用 ChemDraw 原生渲染并给我看 PNG。

常见问题

任意 AI Agent 都能使用这个 ChemDraw Skill 吗？

可以。Agent 只需要能读取 Skill 指令并执行命令行，所有工具都通过 cdx.py 运行。安装脚本会把 Skill 放到 Claude Code、Codex、Gemini CLI、GitHub Copilot、Cursor、OpenCode 等 Agent 能发现的目录；不支持自动发现的 Agent，在它的指令文件里指向 SKILL.md 即可。

必须使用 MCP 服务吗？

不需要。命令行覆盖全部工具，并保留同样的工作进程隔离、ChemDraw 原生锁和超时控制。需要类型化工具调用的客户端仍可使用 MCP。

能从 Excel 实验数据生成 SAR 图和底物拓展图吗？

可以。将可信结构与 CSV/XLSX 数据绑定，生成可编辑的构效关系（SAR）图或底物拓展图；更新数据时保留无关的手工布局修改。见数据驱动绘图指南。

能把文献里的结构图复刻成可编辑 ChemDraw 文件吗？

可以。论文图复刻流程结合 DECIMER 结构识别、结构确认、版式重建与原生视觉复核，输出可编辑 CDXML 和 ChemDraw 原生预览。见重建指南。

没有安装 ChemDraw 能用吗？

可以使用跨平台的 cdxml-toolkit 运行时生成和检查 CDXML（Windows、macOS、Linux）。原生渲染、ChemScript 检查和 Office 嵌入需要 Windows 上已授权的 ChemDraw。

ChemDraw Skill 采用 MIT 许可证。内置工具包基于 Hiu Fung Kevin Lee 的 cdxml-toolkit。
