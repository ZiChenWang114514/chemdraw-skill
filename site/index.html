让 AI 画出可编辑的 ChemDraw 结构式

ChemDraw Skill 让 AI 编程 Agent 能直接做出 ChemDraw 文件。你说要画哪个分子或哪张图，Agent 先查证结构，再写出 CDXML，让 ChemDraw 渲染，并把文件读回来核对。打开来就是一份普通的 ChemDraw 文档，原子和键都能接着改。同一个 Skill 还能算反应周围的数字：试剂用量、收率、表征文字和原子映射。

git clone https://github.com/ZiChenWang114514/chemdraw-skill.git

适用于 Claude Code、Codex、Gemini CLI、GitHub Copilot、Cursor、OpenCode，以及任何能执行命令行的 Agent。

四步，每一步都能检查

图看起来对，化学上也可能是错的。所以每一步都有明确的输入和产物，出了问题，一眼就能看出是哪一步。

四步都从同一个入口 cdx.py 运行，能执行命令行的 Agent 都能调用，MCP 可选。

“阿司匹林”

  1. resolve_nameOPSIN、PubChem

    确认结构

    从名称、标识符、可信 SMILES 或 DECIMER 识别结果出发，并记录来源，不让模型凭空编 SMILES。

    查看命令和输出
    $ cdx.py call resolve_name --json '{"query": "aspirin"}'
{"ok": true, "name": "aspirin", "smiles": "CC(=O)Oc1ccccc1C(=O)O", "formula": "C9H8O4",
 "mw": 180.159, "exact_mass": 180.0423, "source": "reagent_db", …}

    CC(=O)Oc1ccccc1C(=O)O

  2. buildACS Document 1996

    原生绘制

    生成 CDXML，保留立体、电荷和同位素。原子、键和文字都能在 ChemDraw 里接着改。

    查看命令和输出
    $ cat aspirin.json
{"objects": [{"type": "molecule", "smiles": "CC(=O)Oc1ccccc1C(=O)O", "at": [80, 60]}]}
$ cdx.py build aspirin.json aspirin.cdxml
{"cdxml": "…/aspirin.cdxml", "ok": true}

    aspirin.cdxml

  3. renderChemDraw，300 dpi

    渲染查看

    由 ChemDraw 本身渲染，Agent 打开图片，逐项检查标签、箭头、电荷和交叉。

    查看命令和输出
    $ cdx.py render aspirin.cdxml
{"source": "…/aspirin.cdxml", "png": "…/aspirin.png", "ok": true}

    aspirin.png

    回读核对

    保存后重新读取文件，确认写进去的就是要画的结构；读取器之间不一致时如实报告。

    查看命令和输出

反应用量、收率和相关数字

对你以 SMILES 或 ChemDraw 文件给出的反应，cdx.py calc 会运行 ChemDraw 自带的 Structure > Analyze Stoichiometry，并在 ChemDraw 里打开结果。在表里填一个用量，其余数值由 ChemDraw 算出。

  • 每个反应物和试剂的当量、样品质量、摩尔浓度、密度、体积和物质的量；产物的预期质量、实测质量、纯度和收率。
  • cdx.py calc --read 把保存后的计量表以数据返回，智能体引用的是 ChemDraw 的数值，而不是它自己算的。读回不需要 ChemDraw；生成计量表需要桌面版 ChemDraw。
  • 源文件不会被改动：计量表写进一个新副本。
  • 没有 ChemDraw 时，SI 原料表可为最多 100 个反应给出用量、浓度、原子经济性和过程质量强度（PMI），默认值都会标出，并附内置表提供的安全提示；表里没有的显示“未收录”。它只是提醒，不能代替 SDS。
  • 旁边还有：按 ACS 顺序的表征段落（核磁峰数会核对）、多步路线的总收率和 PMI、带反应类型标注的原子映射。

三步开始使用

  • ChemDraw。原生渲染、第 3 步的 PNG 和 Office 嵌入需要 Windows 或 macOS 上已授权的桌面版 ChemDraw。没有它时，Skill 仍可构建、编辑、检查和识别结构，也能使用各类计算器。
  • Python。安装脚本需要 Python 3.9 以上，会自动找到 64 位 Python 3.10–3.13 作为运行时，Windows、macOS、Linux 都能装。
  • 磁盘。默认运行时约占 760 MB。--extras 后不跟名称时只安装核心部分。
  • 可选。加 --opsin 可用 OPSIN 把名称转成结构，它需要 Java（Windows 上自动下载，其他系统需自行安装）。image 依赖组的文字识别需要 Tesseract。

常见问题

任意 AI Agent 都能使用这个 ChemDraw Skill 吗？

可以。Agent 只需要能读取 Skill 指令并执行命令行，所有工具都通过 cdx.py 运行。安装脚本会把 Skill 放到 Claude Code、Codex、Gemini CLI、GitHub Copilot、Cursor、OpenCode、Kimi CLI、pi 等 Agent 能发现的目录；不支持自动发现的 Agent，在它的指令文件里指向 SKILL.md 即可。

必须使用 MCP 服务吗？

不需要。命令行覆盖全部工具，并保留同样的工作进程隔离、ChemDraw 原生锁和超时控制。需要类型化工具调用的客户端仍可使用 MCP。

能从 Excel 实验数据生成 SAR 图和底物拓展图吗？

可以。将可信结构与 CSV/XLSX 数据绑定，生成可编辑的构效关系（SAR）图或底物拓展图；更新数据时保留无关的手工布局修改。见数据驱动绘图指南。

它会编造反应条件或推测机理吗？

不会。按需求画的图，条件、收率和实测数值只取自你给的内容，缺的就保持缺失，并在报告里说明。解析不了的名称会被拒绝，而不是猜一个。机理只按你列出的电子转移绘制，箭头起点没有孤对电子或电荷时会提醒，但不会判断机理本身对不对。见绘制新反应图。

能帮我算每种试剂该称多少吗？

可以，用的是 ChemDraw 自带的计算器。cdx.py calc 对以 SMILES 或 ChemDraw 文件给出的反应运行 Structure > Analyze Stoichiometry，并在 ChemDraw 里打开化学计量表；在表里填质量、体积或当量，其余数值由 ChemDraw 算出；cdx.py calc --read 把保存后的数值读回来。没有 ChemDraw 时，SI 原料表也能给出用量，其中所有默认值都标明是假设值。见化学报告指南。

安全信息可以信到什么程度？

它只是提醒，来自内置的约五十种常用溶剂和试剂表：GHS 图标、H 说明、沸点和闪点。表里没有的物质显示“未收录”，不会显示成安全。请以你实际使用的产品的 SDS 为准。

能把文献里的结构图复刻成可编辑 ChemDraw 文件吗？

可以。论文图复刻流程结合 DECIMER 结构识别、结构确认、版式重建与原生视觉复核，输出可编辑 CDXML 和 ChemDraw 原生预览。见重建指南。

没有安装 ChemDraw 能用吗？

可以使用跨平台的 cdxml-toolkit 运行时生成和检查 CDXML（Windows、macOS、Linux）。原生渲染、ChemScript 检查和 Office 嵌入需要 Windows 或 macOS 上已授权的桌面版 ChemDraw。
