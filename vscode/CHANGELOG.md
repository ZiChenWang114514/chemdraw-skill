# Changelog

## 0.7.0

- Initial release of the ChemDraw 2D Studio & Mol* 3D Workbench `.vsix` extension.
- Added Reaxys / SciFinder 4-docked 2D chemical structure & substructure query editor (`chemdraw.openStudio` & Activity Bar dockable WebviewView).
- Added native two-way `CustomTextEditorProvider` for `.cdxml`, `.mol`, and `.sdf`, plus 3D `CustomReadonlyEditorProvider` for `.pdb`, `.cif`, `.mmcif`, and `.xyz`.
- Added universal `Transfer to Agent` multi-harness chat bridge, live `studio-live` watcher, Workspace Structures tree, SMILES hover links, and 300 DPI native ChemDraw PNG action.
